# 宿命刻の姫君 構成台帳（ドライブ版）

シリーズ構成・各話プロット・キャラクター設定を編集するアプリです。

- タブレットやPCのブラウザで動き、ホーム画面に追加すればオフラインでも開けます
- 編集内容はまず端末の中に保存されます
- 「同期」を押すと Google ドライブの台帳データと突き合わせ、新しい方を反映します
  - 両方で変わった項目は、どちらを残すか選べます
  - 削除と画像も同期されます

物語のデータは、このアプリ（GitHub に置くファイル）には入っていません。データは各端末の中と、あなたの Google ドライブだけに保存されます。

---

## 1. アプリを GitHub Pages に置く（1回だけ）

1. GitHub にログインし、右上の「＋」→「New repository」を選ぶ
2. 次のように入力して「Create repository」を押す
   - Repository name：`kozo-daicho`（ほかの名前でも可）
   - 公開範囲：**Public**（無料で GitHub Pages を使うため。物語のデータは入らないので公開で問題ありません）
3. このフォルダの中身を、リポジトリに置く
   - 自分で置く場合：リポジトリの画面で「uploading an existing file」を選び、フォルダの中身（`index.html` などと `icons` フォルダ）をまとめてドラッグして「Commit changes」
   - Claude に頼む場合：リポジトリ名（例：`ユーザー名/kozo-daicho`）を伝えると、こちらで置けます
4. リポジトリの「Settings」→ 左の「Pages」を開く
   - Source：「Deploy from a branch」
   - Branch：「main」と「/ (root)」を選んで「Save」
5. 1〜2分待つと、アプリのアドレスが表示されます
   - 例：`https://ユーザー名.github.io/kozo-daicho/`
   - このアドレスは次の手順で使います

## 2. Google ドライブを使えるようにする（1回だけ、10〜15分）

アプリがドライブにアクセスするための許可を設定します。アプリが触れるのは、**アプリ自身が作ったファイルだけ**です（ほかのファイルは見えません）。

1. https://console.cloud.google.com/ を開き、台帳を保存したい Google アカウントでログインする
2. 上部のプロジェクト選択から「新しいプロジェクト」を作る
   - 名前：`kozo-daicho` など
3. 左のメニュー「API とサービス」→「ライブラリ」で「Google Drive API」を検索し、「有効にする」を押す
4. 「Google Auth Platform」（または「OAuth 同意画面」）を開き、「開始」を押す
   - アプリ名：`構成台帳` など
   - サポートメール：自分のアドレス
   - 対象：「外部」
   - 連絡先：自分のアドレス
5. 「対象」（Audience）で、「テストユーザー」に自分の Gmail アドレスを追加する
   - 公開ステータスは「テスト中」のままで大丈夫です
6. 「データアクセス」で「スコープを追加または削除」を押し、`.../auth/drive.file` にチェックを入れて保存する
7. 「クライアント」で「クライアントを作成」を押し、次のように入力して「作成」
   - アプリケーションの種類：「ウェブ アプリケーション」
   - 承認済みの JavaScript 生成元：`https://ユーザー名.github.io`
     - 末尾に `/` やリポジトリ名は付けません
8. 表示された「クライアント ID」（`〜.apps.googleusercontent.com`）をコピーする
9. リポジトリの `config.js` を開いて鉛筆マークで編集し、`CLIENT_ID: ""` の `""` の中に貼り付けて「Commit changes」
   - Claude に ID を伝えてもらえれば、こちらで書き換えます
   - クライアント ID は秘密の情報ではないので、公開しても問題ありません

## 3. タブレットで使い始める

1. タブレットの Chrome でアプリのアドレスを開く
2. 右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）
3. ホーム画面のアイコンから開く
4. 最初の1台目は「ファイルを選ぶ」で移行データを取り込む
   - 移行データ：`宿命刻の姫君_移行データ.json`
   - Gmail に添付するか、ドライブに置いてタブレットに保存してから選びます
5. 「同期」を押して Google にログインする
   - 「このアプリは Google で確認されていません」と出たら、「詳細」→「構成台帳（安全ではないページ）に移動」で進みます。自分で作ったアプリなので問題ありません
6. 2台目以降（PC など）は、取り込みは不要です。「同期して読み込む」を押すだけで、ドライブから全部読み込みます

## 使い方のポイント

- **保存**：入力は0.3秒ほどで端末に保存されます。ネットは要りません
- **同期**：オンラインのときに「同期」を押します。赤い数字は、まだドライブに送っていない変更の数です
- **両方で変更したとき**：同じ項目を2台で変更していると、同期のときにどちらを残すか聞かれます
- **ドライブ上の保存先**：マイドライブの「宿命刻の姫君_構成台帳」フォルダ
  - 台帳データは `kozo-data.json`、画像も同じフォルダに入ります
  - Google Drive コネクタをつないだ Claude からも読めます
- **端末のデータが消えたとき**：ブラウザのデータ消去などで消えても、ドライブと同期済みの分は「同期」で戻ります
- **控え**：「方針・編」タブの「控えを書き出す」でファイルに保存できます
- **ログインの確認画面**：テスト中のアプリなので、ときどき（目安は週1回ほど）Google のログイン確認がもう一度出ることがあります

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `styles.css` / `app.js` | 画面 |
| `store.js` | 端末内の保存（IndexedDB） |
| `drive.js` | Google ドライブとの同期 |
| `config.js` | Google のクライアント ID |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフライン動作とホーム画面用 |

アプリを更新したときは、`sw.js` の `VERSION` の数字を上げると、各端末が次に開いたときに新しい版へ切り替わります。
